## 2. Техническое состовляющие проекта.

# 2.1 Стек.

IDE: Visual Studio Code;
Web-site: React;
Мобильное приложение(Android/iOS): Flutter;
Backend(единый сервер): Python;
Нейросеть: OpenRouter(модель с Vision для определения загрязнения по снимку с карты Яндекса) и OpenRouter(модель для чата);
База данных: PostgeSQL + расширение PostGIS;

# 2.2 Cхема работы системы.

[ Мобилка (Flutter) ]   \
                         ===> [ REST API (Бэкенд: Python) ] ===> [ PostgreSQL / PostGIS ]

                                          || (Снимки ДЗЗ / Фото)
                                          \/
                                 [ OpenRouter API ] (Vision ML)

## 3. Идея реализации.

# 3.1 Логика работы проекта.

После скачивания приложения пользователь первоначально попадает на вкладку регистрации/входа на свой аккаунт (кнопка регистрации перенаправляет на сайт. После входа в аккаунт в дальнейшем, при запуске приложения, по умолчанию открывается "Карта") => На вкладке "Карта" отображается Яндекс пользователь может открыть вкладку "Задания" и у него появляется выбор из двух вариантов => Нажав кнопку "Поиск загрязнённых мест" у пользователя открывается втроенная в приложение камера, которая при фотографировании фиксирует координаты и время. Фото вместе с метаданными отправлеется в нейросеть, которая с помощью vision определяет степень загрязнения
